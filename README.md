A one-line developer excuse for when code breaks in production, written to
`/output/entry.txt` by `main.py` (Python 3.13), for the make.fun competition
[Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3).

> It worked on my machine — production is the same code, only now it has an audience, stage fright, and a pager.

Run it: `MAKEFUN_OUTPUT_DIR=out python3 main.py` — writes `out/entry.txt`
(110 characters, 112 bytes, one line, no trailing newline).
